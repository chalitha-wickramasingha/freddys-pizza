# 📱 Freddy's Pizza Mobile Application

Freddy's Pizza is a modern mobile food ordering application that allows customers to browse menu items, place orders, manage their cart, and experience a seamless pizza delivery workflow.

Built with React Native and Expo, the application focuses on performance, usability, and a clean mobile-first user experience.

---

## 🚀 Features

- 🔐 Secure User Authentication
- 🍕 Interactive Menu Browsing
- 🛒 Shopping Cart Management
- 📦 Order Placement & Tracking
- ⚡ Real-Time Updates
- 📱 Modern Mobile User Interface
- 🎯 Responsive Mobile Experience

---

## 🛠️ Technology Stack

- **React Native**
- **Expo SDK 55**
- **TypeScript**
- **Clerk Authentication**
- **Convex Backend**

---

## ⚙️ Local Development

### Install Dependencies

```bash
npm install
```

### Start Expo Development Server

```bash
npx expo start
```

---

## 📂 Project Role

This application serves as the customer-facing mobile platform within the Freddy's Pizza ecosystem.

The administrative dashboard can be found in the `admin/` directory.
