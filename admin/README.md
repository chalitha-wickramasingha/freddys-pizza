# 🍕 Freddy's Pizza Admin Dashboard

The Freddy's Pizza Admin Dashboard is the administrative platform responsible for managing restaurant operations, menu items, customer orders, and business workflows.

Built as part of the Freddy's Pizza full-stack ecosystem, this application enables administrators to efficiently monitor and manage the food delivery platform through a modern web-based interface.

---

## 🚀 Features

- 🔐 Secure Authentication & Authorization
- 📦 Order Management
- 🍕 Menu & Product Management
- 👥 Customer Management
- ⚡ Real-Time Data Synchronization
- 📊 Business Insights & Analytics
- 🛠️ Administrative Controls

---

## 🛠️ Technology Stack

- **Next.js**
- **TypeScript**
- **Convex**
- **Clerk Authentication**
- **Tailwind CSS**

---

## ⚙️ Local Development

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

---

## 📂 Project Role

This application serves as the administrative backend for the Freddy's Pizza platform.

The customer-facing mobile application can be found in the `mobile/` directory.
